# Roadmap

| Phase | Scope | Status |
|---|---|---|
| **1. Foundations + Solo MVP + Feedback + Beta** | Cuppa (1:1 with 7 Locals, 6 scenarios), The Briefing, Playback, PWA, cost guards, full docs | ✅ Built (v0.1.0) |
| 2. Accounts & premium voices | Sign-in, cloud-synced history, premium regional TTS (Azure/ElevenLabs), pronunciation scoring, phrase deck with spaced repetition, Capacitor app-store builds | Planned |
| 3. Huddle: multi-avatar rooms | 2–3 Locals in one conversation with a "floor manager" for turn-taking; moderated debates (Soapbox) | Planned |
| 4. Friends in the room | Invite links, 5-person rooms (real-time audio, e.g. LiveKit), consent flow | Planned |
| 5. Monetisation | Stripe subscriptions (Free / Plus / Pro / Group), minute metering, cost dashboard | Planned |
| 6. Public launch | Analytics, UK GDPR documentation, marketing site | Planned |

Feature names reserved for later phases: **Huddle** (multi-Local room), **Soapbox** (debate mode), **Phrase Deck** (spaced repetition).
